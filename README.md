  ## 🚀 快速开始

  ### 本地开发

  ```bash
  # 安装依赖
  npm install

  # 启动开发服务器
  npm run dev

  # 构建生产版本
  npm run build

  # 预览构建结果
  npm run preview
  ```

  ## 📝 项目说明

  这是一个交互式的星空主题网站，展示昂宿星团（七姐妹星团）的7颗恒星。每颗星星都包含天文知识和个性化祝福。

  ### 主要功能

  - ✨ 欢迎动画和对话
  - 🌟 交互式星图
  - 📖 星星详情页面
  - 🎵 背景音乐播放
  - 🎁 最终祝福消息
